====================
why we are not able to login to ansible using windows powershell-
Issues we faced
1. Wrong IP address: Initially, we used 127.0.2.1, which is a loopback address.
2. SSH host key changed: Windows had stored an old SSH fingerprint.
3. SSH authentication failed: The ansible user didn't exist on the Ansible VM, but we were trying to connect using ansible@192.168.56.10.

How we fixed them
1. Found the correct VM IP using ip -br addr: 192.168.56.10.
2. Removed the old SSH fingerprint using:
   ssh-keygen -R 192.168.56.10
3. Created the ansible user:
   sudo useradd -m -s /bin/bash ansible
4. Added the Windows public key to:
   /home/ansible/.ssh/authorized_keys
5. Fixed SSH directory and file permissions.
6. Verified that the ansible user exists and can log in.

What we need to configure
There are four main steps:
1. Jenkins plugins: Install Git and GitHub integration plugins.
2. GitHub credentials: Configure authentication so Jenkins can access your repository.
3. GitHub webhook: Configure GitHub to notify Jenkins when code is pushed.
4. Jenkins pipeline: Configure Jenkins to trigger builds when changes arrive.

Important: If Jenkins is running on your laptop using localhost:8080, GitHub cannot directly reach it over the internet. We'll need a secure tunnel or another webhook-accessible endpoint.
